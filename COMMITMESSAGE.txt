io: a missing taxonomy rank is not a group

major_groups collapses a taxonomy into the handful of groups a figure can
show, trying each rank in turn and letting a row fall through to the next rank
when its value is absent. The emptiness check was written as

    if raw and str(raw).strip()

which is correct for a value read with csv, where an absent cell arrives as "".
It is wrong for the documented input. ``table`` is a DataFrame, pandas reads an
absent cell as NaN, NaN is TRUTHY, and str(NaN) is "nan" -- so the row did not
fall through. It formed a group of its own, named "nan", and took a colour and a
legend entry.

The fault is invisible through csv and appears only through a DataFrame, which
is why it survived: the same file read either way gives "" or NaN, and only one
of those was handled.

Found on the invertebrate subtree of the FXR1 family, where exactly one of 57
sequences has no phylum -- Salpingoeca rosetta, a choanoflagellate, and the
taxonomically most informative tip on that tree, since it is the only
non-metazoan in a set of metazoan single-copy orthologues. Labelled "nan" it
was indistinguishable from a parsing accident. So the bug did not merely add a
legend entry: it concealed the one fact the figure existed to show. With the
rank treated as missing the row falls through to class and the legend reads
Choanoflagellata.

_rank_value centralises the test. NaN is detected by raw != raw, which is true
of NaN alone, inside a try/except TypeError so that a value whose comparison
raises is treated as present rather than crashing the call. The string forms
are rejected too -- "nan", "none", "na", "<na>", "null" and whitespace -- because
a table that has been through a CSV round-trip carries the word rather than the
float, and a group named "none" is the same defect wearing a different spelling.

Two tests. The first pins the DataFrame case that failed: a row whose phylum is
None must come back as its class, and "nan" must not appear among the group
names. The second pins the spellings, each on its own row, so a regression
names which form slipped through rather than reporting one opaque failure.
