feat(phylo): a constrained root, nodes left to be estimated, and a bracket

Two collisions that drop_unresolvable could not see, and a way to bound a
duplication without a clock. Both came from the same run: a set of 96
calibrations that dated cleanly with a free root, and failed the moment a root
bound was added, with LSD2 naming neither the nodes nor the ages.

drop_unresolvable looked for one kind of collision only -- two calibrations
merged by branch collapse onto one node, which is two dates for one node. It
found those. It could not find either of the other two, and for the same
reason in both cases: nothing in the calibration set contradicts anything, so
no check on the set alone can see it.

A calibration that collapses onto the ROOT is consistent with every other
calibration. It becomes a contradiction only when the run pins the root, which
is why a set that worked can stop working when a root bound is added and
nothing about the set has changed. root_age now names that age, and
calibrations in the root's merge group are dropped against it.

A calibration that collapses onto a node whose age is the RESULT is worse,
because it does not fail. The node carries exactly one age, the run reports
nothing unusual, and the duplication's date comes back as whatever the species
tree put there. The output then agrees with the literature because it came
from the literature, which is the circularity the whole scheme was built to
avoid: calibrations go on speciations inside the paralogue clades and never on
the duplications, precisely so that the duplication ages are estimated rather
than asserted. Branch collapse puts them there anyway. estimate= names those
nodes by pairs of descendant tips and the collision is caught.

Each dropped calibration now carries a reason, and format_dropped groups by it
rather than by clade, because the three are not the same problem and do not
have the same fix.

bracket() is the other half. A duplication is older than any speciation
retained in BOTH daughter lineages and younger than the shallowest speciation
at which the daughters are not all present. Both bounds are speciation ages
read off the dated species tree; neither uses a branch length of the gene tree.

That matters because the gene tree's branch lengths are the part rate
heterogeneity corrupts, and on this family it is not a small effect. Three
measurements, each with elapsed time held constant by construction: two copies
in one chondrichthyan genome give root-to-tip 0.6522 against 0.3131, a ratio of
2.08 at support 100 on both nodes; within one paralogue group, mammals run
0.002-0.018 against teleosts at 0.40-0.49; within one cyclostome duplication,
one daughter pair carries 0.192 and 0.151 against 0.699 and 0.357 in the other.
A single global rate is therefore false as a premise rather than approximate as
a model, and a point estimate from a strict clock states the clock rather than
the sequences. The least-squares run that prompted this returned a root age of
-7487 Myr, older than the Earth.

Two decisions inside bracket() are worth naming because they could reasonably
have gone the other way.

The upper bound is set only by species the GENE tree holds. A species in the
species tree with no gene in the analysis is absence of evidence: it may carry
every daughter and simply not have been searched, and letting it bound the
answer would convert a gap in the sampling into a result. With nothing sampled
that lacks a daughter, the function raises instead of inventing a bound.

A lower bound needs two witnesses. One species cannot witness a speciation, so
a node where only one species carries a gene in every daughter is refused
rather than given its own age as a bound.

The bounds can meet, and then there is no interval. That happens when a species
nested inside the clade carrying the lower bound has a gene but not in every
daughter -- ordinarily loss, which the bracket cannot distinguish from never
having had the paralogue, and otherwise a gene tree that disagrees with the
species tree or a sequence in the wrong daughter. Bracket.empty reports it and
format_bracket names the species that closed the interval, rather than printing
a width of zero as though it were precision.

The width is not uncertainty. It is the resolution the taxon sampling affords,
and it narrows only when a species branching between the two bounds is added --
not by more sequences of species already inside. On the set this was written
for, adding a lamprey, a hagfish and a chimaera took the interval from more
than 150 Myr to under 40.
